# BlockForge logo

A glowing ember block resting on an anvil, on a green rounded tile. The greens follow
`src/main/java/com/blockforge/launcher/gui/modern/Palette.java`; the ember oranges are the only secondary colour.

| File | Use |
| --- | --- |
| `blockforge-icon.svg` | Master icon (48 px and up) |
| `blockforge-icon-small.svg` | 24 to 32 px: no sparks or seams, larger shapes |
| `blockforge-icon-16.svg` | 16 px, drawn pixel by pixel |
| `blockforge-icon-macos.svg` | macOS grid (824 px tile on a 1024 canvas) |
| `banner.svg`, `banner-dark.svg` | README banner for light and dark backgrounds (text is outlined, no font needed) |
| `splash.svg` | Source of the launcher splash screen |
| `png/blockforge-*.png` | Icon PNGs from 16 to 1024 px |

## Re-exporting

All SVGs and every image the launcher uses are generated by `export.py`. Edit the shapes or colours there, then run
from the repository root:

```sh
pip install --user cairosvg fonttools uharfbuzz pillow
python3 docs/logo/export.py
```

It rewrites:

- the SVGs, `banner*.png` and `png/` in this folder
- `src/main/resources/assets/image/icon.png` (256), `icon-osx.png` (1024, with shadow), `icon.ico`
  (16, 24, 32, 48, 64, 128, 256), `icon.icns` (16 to 1024, including @2x) and `splash-screen.png` (576x192)
- `atlauncher.png` (128) and `atlauncher.svg` in `packaging/linux/_common` and `packaging/aur/*`

The wordmark uses Roboto Bold and Regular from `src/main/resources/assets/font/`.
