## 1. nbt/** - 24 files, 3830 lines
Files: `nbt/TagType.java`(114) registry; `nbt/tags/Tag.java`(773) abstract base + ALL static file/compress helpers; `tags/TagWithName.java` record; `tags/primitive/{Byte,Short,Int,Long,Float,Double}Tag` (88 each, boilerplate), `StringTag`(144); `tags/array/{Byte,Int,Long}ArrayTag`(~130 each); `tags/collection/{CompoundTag(822),ListTag(305)}`; `nbt/io/{Reader,Writer}` interfaces + `DataInputReader{BE,LE,Java}`, `DataOutputWriter{BE,LE,Java}`; `io/ByteString`.

### Tag model
- Type ids (TagType.ordinal, standard): END0 BYTE1 SHORT2 INT3 LONG4 FLOAT5 DOUBLE6 BYTE_ARRAY7 STRING8 LIST9 COMPOUND10 INT_ARRAY11 LONG_ARRAY12. `TagType.getById` throws IllegalArgumentException for id>12 (readers use unsigned byte).
- Only these 13 types. NO varint / "network" NBT variant, no SNBT parser (only write-only `toSNBT()`, used just for logging missing mappings and toString).
- Java generic hierarchy `Tag<T>` -> Rust: `enum Tag { Byte(i8), Short(i16), Int(i32), Long(i64), Float(f32), Double(f64), ByteArray(Vec<u8>), String(NbtString), List(ListTag), Compound(Compound), IntArray(Vec<i32>), LongArray(Vec<i64>) }` + `enum TagType` with `id()`/`from_id()`.
- Equality: same class AND value equal (ByteTag(1) != IntTag(1)); null value == empty (compound/list/array). Float/Double compare via boxed Objects.equals (bit semantics: NaN==NaN, 0.0 != -0.0) - Rust `==` differs; implement manually if tests rely on it. Compound equality is order-insensitive (Map.equals). `hashCode` consistent. `clone()` is deep.
- Strings: `ByteString` holds raw bytes OR String lazily (equals/hash on UTF-8 bytes) so invalid UTF-8 from Bedrock round-trips. Rust: `NbtString(Vec<u8>)`/`Box<[u8]>` with `to_str() -> Cow<str>` (lossy) and `From<&str>`; do not store `String` only. MAX_STRING_LENGTH = 32767 (check on read: BE/LE = byte length 0..=32767, negative short rejected; Java reader checks `str.length()` in UTF-16 chars AFTER readUTF).
- Containers: Compound = `Map<String,Tag>` backed by `Object2ObjectLinkedOpenHashMap` => INSERTION ORDER is preserved on read/write/clone; `put` of existing key keeps original position, replaces value; remove keeps others' order. Rust: `indexmap::IndexMap` and use `shift_remove` (NOT swap_remove). Map allocated lazily (`null` = empty); `getValue()` returns empty map. MAX_COMPOUND_LENGTH = 16*16*4096 = 1,048,576 entries, MAX_NAME_LENGTH = 256 (name read limit; names > 256 bytes -> error). Duplicate names on read: later wins (value.put) but size check counts distinct.
- ListTag: `{ listType: Option<TagType>, items }`. Constructors infer type from first element; `add()` on empty list sets type from the element; NO check that later elements match type. Encode: writes type id (END if null), int length (value.size), then each element's `encodeValue` (only if listType != null && != END!). Decode: reads type id + int length; length < 0 or > 1,048,576 -> error; if type END or length==0 -> `listType=END` and EMPTY (no elements; older versions use BYTE for empty lists, normalised to END). Elements have no id/name.
- Arrays: length prefix int; MAX_ARRAY_LENGTH = 65536 ELEMENTS for byte/int/long arrays on decode (length<0 or >65536 -> IllegalArgumentException). Encode has no limit. (Decision for port: keep as safety default but make configurable; real chunk data < 65536.)
- Primitives: ByteTag(i8), etc. Java `ByteTag` is also used for booleans (see settings convertType).
- toSNBT: Byte `1b`, Short `1s`, Int `1`, Long `1l`, Float `1.0f`, Double `1.0` (Java Double.toString - differs from Rust Display for exponents), String `"..."` with control chars (<=0x1F, 0x7F) as `\uXXXX` upper-hex and `"` as `\"`; list `[a,b]`; arrays `[B;1b,2b]`, `[I;1,2]`, `[L;1l]`; compound `{key:val}` key quoted+escaped only if it contains `"`. Needed only for log messages - low priority.

### Reader/Writer (nbt/io)
- `Reader`/`Writer` interfaces: readShort/Byte/UnsignedByte/Int/UnsignedInt24/Long/Float/Double/readBytes + `readString(max)`, `readShortPrefixedBytes(max)`; Writer mirror + `writeString`, `writeUnsignedInt24`. Also used OUTSIDE NBT for raw binary: Bedrock chunk/ColumnWriter (`Writer.toBedrockWriter`), Preview map.bin (LE), MCA header (`Reader.toJavaReader(RandomAccessFile)`, 24-bit offsets via readUnsignedInt24).
- Three flavours: `BE` (plain DataInput/Output big-endian; strings = u16 length + raw UTF-8, length must be 0..=max), `Java` (= BE but strings use `readUTF/writeUTF` => JAVA MODIFIED UTF-8 (NUL as C0 80, supplementary chars as surrogate pairs, 3 bytes each), u16 length; writeUTF throws if >65535 encoded bytes), `LE` (Bedrock: little-endian short/int/long/float/double/int24, strings = LE i16 length + raw UTF-8; readByte unsigned/signed variants as expected). `toBedrockReader == toLittleEndianReader`. Rust: generic `trait NbtRead`/`NbtWrite` or enum {Be, Java, Le} flag over `std::io::Read/Write` with `byteorder`; Java modified-UTF-8 via `cesu8` crate (`cesu8::from_java_cesu8` / `to_java_cesu8`) - NOT plain UTF-8.
- Java Reader returns strings as decoded-then-re-encoded standard UTF-8 bytes (ByteString built from String), so after reading Java NBT bytes are always valid UTF-8.

### File / compression helpers (all in `Tag.java`, ~40 near-duplicate methods) -> collapse to ONE generic fn in Rust
- Root = always named compound; `encodeNamed(writer, "", root)` writes id(10), name (empty string) then compound body ending with END(0). Read: `decodeNamed(reader, CompoundTag)` -> None if first byte is END; name ignored. A root that is not a compound = ClassCastException.
- Java: `readUncompressed/GZip/ZLib/LZ4JavaNBT(byte[]|File)`, `readPossibleGZipJavaNBT(File)` (peek 2 bytes == 0x1F 0x8B => gzip else uncompressed; used for map_*.dat?), `write{Uncompressed,GZip,ZLib}JavaNBT` (ZLib uses Deflater BEST_SPEED = level 1; GZip default level). **All Java read helpers unwrap**: if root has compound "data" return it, else compound "Data", else root (level.dat has "Data", map.dat "data"). Writers do NOT wrap (caller builds the "Data" wrapper).
- Bedrock: `readBedrockNBT(File)` skips 8-byte header (LE i32 storageVersion, LE i32 payloadLen) then reads LE NBT (level.dat); `readBedrockNBT(byte[]|ByteBuffer)` reads LE NBT with no header (LevelDB values; no unwrap). `writeBedrockNBT(root)->bytes`, `writeBedrockNBT(File, storageVersion, root)` writes header(storageVersion, len) + payload. Bedrock reading of several concatenated NBT roots from one stream (palettes, block entities in LevelDB values) uses `Tag.decodeNamed(reader, CompoundTag.class)` in a loop until EOF/END (BedrockColumnReader l.193/237, v1_18_30 ColumnReader) - Rust needs `decode_named(&mut impl NbtRead) -> Result<Option<(String, Tag)>>` and `encode_named` public.
- Compression ids in MCA: 1 gzip, 2 zlib (default), 3 none, 4 LZ4Block (MCAReader/JavaLevelReader l.122-125). Writer always zlib (JavaWorldWriter l.118).

## 3. scheduling/** - 17 files, 1587 lines (+ pkg/pruning)
Hierarchical, weighted, priority-scheduled async task system built on `CompletableFuture`. Classes: `task/Task` (interface w/ static factories `async`, `asyncConsume`, `asyncForEach`, `asyncUnwrap`, `join`, `flatJoin`, `unwrap`, `environment`, `signal`; defaults `then/thenConsume/thenUnwrap`), `TrackedTask` (name, weight, status PENDING/STARTED/DONE, children list, depth, ThreadLocal stack of "current task"), `WrappedTask`/`WrappedTaskConstant` (runs a lambda; completes only when ALL CHILDREN complete; then frees itself), `Environment` (root TrackedTask owning TaskExecutor; `close()` = "no more root tasks"), `TaskExecutor` (N daemon-ish threads on a `PriorityBlockingQueue`), `TaskExecutorSupplier`, `TaskWeight`, `ProgressiveTask`, `FutureTask`, `TaskMonitorThread`, `LoggedException`, `function/*` (throwing lambda ifaces).
Key semantics a port MUST keep:
1. **Parent/child by dynamic scope**: a task created while another task's lambda is running (thread-local stack `currentTaskStack`, InheritableThreadLocal executor) becomes its child; a task's future completes only after its lambda AND all its descendants completed (`waitForChildren`). `then(...)` continuations are children of the task that was current when `then` was *called* ("progress belongs to the branch it was made in") and run on whichever thread completed the previous future (no re-queue). Creating a task after parent is DONE throws; creating one outside an Environment throws.
2. **Progress**: `getProgress()`: PENDING 0, DONE 1, STARTED = sum(child.progress*child.weight)/(selfWeight(=1)+sum(child.weight)), 0 if no children yet. DONE nodes drop children. Weights: NONE0 LOW1 MEDIUM50 NORMAL100 HIGH200 HIGHER500 HIGHEST1000 (arbitrary; bedrock reader reserves remaining batches' weight with `new TaskWeight(n*(NORMAL+MEDIUM))`). Env weight 0 itself. `getDetailedProgress()` debug tree dump.
3. **Scheduling priority**: executor priority = `(depth<<48)|globalCounter`, comparator is *reversed* long => HIGHEST depth first, and within equal depth the NEWEST (largest counter) first (LIFO, despite the comment). Deeper tasks (column processing/writing) beat shallow ones (reading more regions) => this is the implicit memory bound for the Java reader (no semaphores anywhere in repo).
4. **Threads**: `WorldConverter.convert` creates `Task.environment("World Conversion", 8, ...)` -> hard-coded 8 workers (+ separate monitor thread). OutOfMemoryError in worker => `System.exit(12)`.
5. **Failure model**: any exception thrown inside any task -> `WrappedTask.setupFuture` wraps it once in `LoggedException`, calls `executor.handleException` -> `WorldConverter.logFatalException` => `cancel(throwable)` => whole environment aborts (executor.shutdown interrupts workers + clears queue; root future completed exceptionally). Readers/writers catch recoverable stuff themselves and call `converter.logNonFatalException` (sets `exceptions=true`, prints). `cancel(null)` => CancellationException => reported as "The process was cancelled".
6. **Signals**: `Task.signal(name,val)` -> executor's signalConsumer (only use: `"signal_compaction"` Boolean from BedrockLevelWriter.flushLevel around LevelDB compactRange -> UI "Compacting output").
7. **Free**: `Environment.free()` runs once root's children are done (success OR failure/cancel): calls `reader.free()` then `writer.free()` (each wrapped in try/catch -> logNonFatalException), then shuts down executor.
8. `TaskMonitorThread`: polls every 50 ms, emits progress when |delta| >= 0.0001, stops when future done or progress>=1; then invokes completion handler (Optional<Throwable>). CLI polls every 100 ms itself.
### Rust redesign (src/convert/sched/, ~350-450 lines)
Do NOT port CompletableFuture. Proposed: `Environment { pool: ThreadPool(n=8 default), root: Arc<Node>, cancelled: AtomicBool, first_error: Mutex<Option<Error>> }`; `Node { name, weight, state: AtomicU8, pending: AtomicUsize (self+children), children: Mutex<Vec<Arc<Node>>>, depth, on_done: Mutex<Vec<Box<dyn FnOnce()+Send>>> }` forming a countdown tree. `Scope/TaskCtx` passed explicitly (`ctx.spawn(name, weight, |ctx| ...)`, `ctx.then(...)` registering on_done) instead of thread-locals. Pool: custom workers over `BinaryHeap<(depth, seq)>` + Condvar (rayon has no priority; `rayon::scope` structured-join is a simpler fallback if priority/LIFO order proves unnecessary - but depth-first ordering is what bounds memory, so keep a priority queue). Handlers return values synchronously (see sec 4): `Task<T>` returning futures are only needed for `convertLevel -> WorldHandler` and `convertWorld -> ColumnHandler`; model as `Arc<OnceLock<Option<Arc<dyn ...>>>>` set by the spawned writer task, with continuation `then`. Cancellation: AtomicBool checked by pool before running each job + clear queue (cannot interrupt blocking IO; fine). Progress: `env.progress()->f64` computed over Node tree; expose `Arc<dyn Fn(f64)>` or channel + 50 ms monitor thread to match the 0.0001 deadband. Errors: `Result<(), ConvertError>` from jobs; first Err => set cancelled, store error, clear queue. Panics: `catch_unwind` per job -> fatal error.

### End-to-end flow (exact)
1. Caller builds `WorldConverter`, sets options, `EncodingType.findReader`, `findWriter("JAVA_1_20_5"|"BEDROCK_R20_80"|"INPUT")`, calls `convert(reader, writer)`.
2. `convert`: reset cancelled/exceptions/missing; create Environment(8 threads); `writerHandler = LevelWriterConversionHandler(writer)`; `Pipeline(writerHandler)` with
   - level handlers: `[LevelHandler]`  - world handlers: `[WorldHandler]`  - column handlers: `[ColumnPreTransformWriterConversionHandler(writer::getPreTransformManager, delegate, allowed), (if processColumnPreTransform) ColumnPreTransformConversionHandler]` (compose = list order is inner->outer; the LAST is called first by the reader).
   - Schedules ONE root task `"Reading Level"` (HIGH weight NORMAL) = `reader.readLevel(pipelineHandler)`; `finally` env.close() and sets free callback.
3. Reader (e.g. JavaLevelReader.readLevel): `readCustomDimensions`; async "Collecting Level Data" (parse level settings/maps/POI/player/portals in parallel subtasks, join) -> `levelHandler.convertLevel(ChunkerLevel)` which returns `Task<WorldConversionHandler>` (null result = writer is not interested in worlds).
4. Pipeline Level handler chain on convertLevel: `LevelHandler` (a) if `maps` override set -> `level.setMaps`, (b) drop maps/portals whose dimension is unmapped, remap others via `getNewDimension`, (c) `settings.toJSON()` + overlay `changedSettings` JSON keys (shallow `putAll`) + `ChunkerLevelSettings.fromJSON` => settings; (d) store `level` in converter; then `LevelWriterConversionHandler.convertLevel` = async "Writing Level" `writer.writeLevel(level)` -> wrap returned WorldWriter in `WorldWriterConversionHandler` (null stays null).
5. Per dimension (registry iteration; only if dimension folder exists && `shouldProcessDimension`): async "Reading World" -> `JavaWorldReader.readWorld`: scans `region/*.mca` (name `r.X.Z.mca`, size>=4096), builds `ChunkerWorld(dimension, Set<RegionCoordPair>)`, calls `worldHandler.convertWorld(world)`. `WorldHandler` remaps `world.dimension` via `getNewDimension` or returns an empty task (skip dimension). `WorldWriterConversionHandler` async "Writing World" -> `writer.writeWorld(world)` returns `ColumnWriter?` -> `ColumnWriterConversionHandler`.
6. Reader then (as continuation) reads regions: for each region passing `shouldProcessRegion`: task "Reading region file" -> per column task "Processing column x,z" (skips `shouldProcessColumn`) builds `ChunkerColumn` (also runs reader-side `PreTransformManager.solve(column, processColumnPreTransform)`) -> `columnHandler.convertColumn(column)` (non-blocking: pipeline wraps in task "Running column middleware"). After a region's tasks (incl. descendants) finish: `columnHandler.flushRegion(region)`. After ALL regions: `flushColumns()`, then `worldHandler.flushWorld(world)`, after all worlds `flushWorlds()`, after worlds `levelHandler.flushLevel()` (Bedrock writer: writeBiomeList + LevelDB compaction + signal).
   Bedrock reader streams explicitly: regions ordered BFS over 8-neighbourhood (seeds sorted by x then z), processed in batches of `MAX_IN_FLIGHT_REGIONS=4`; next batch scheduled only when the whole current batch (reads + writer tasks) completed => hard cap on in-flight full columns. Java reader submits all regions at once (relies on depth priority).
7. Column middleware chain per column: `PipelineColumnConversionHandler` task -> `ColumnPreTransformConversionHandler.convertColumn` (synchronized) -> after neighbours resolved -> `ColumnPreTransformWriterConversionHandler.convertColumn` (calls writer's `PreTransformManager.solve(column, allowed)` then delegates) -> `ColumnWriterConversionHandler.convertColumn` => async "Writing Column" `writer.writeColumn(column)`.
8. Completion: env future done when every task tree finished -> free(): reader.free(), writer.free(); monitor reports result; Messenger reports `{missingIdentifiers:[{identifier,type,value}], anonymousId (only if non-fatal exceptions occurred)}`.
Rust: implement handlers as three traits `LevelHandler/WorldHandler/ColumnHandler` (+ `Pipeline` that builds the decorator chain and runs each call as a scheduler task). Because `convertLevel/convertWorld` hand back an async handle, signature: `fn convert_level(&self, ctx:&TaskCtx, level: ChunkerLevel) -> Handle<Option<Arc<dyn WorldHandler>>>`.

### Pre-transform (handlers/pretransform/**)
- Purpose: block states that depend on neighbours (fence/pane/wall connections, stair shape, door halves, chest sides, redstone, fire, stems, tall plants, note block instrument, hanging plants, fence-gate in_wall) cannot be computed per-chunk at column edges. A reader registers per-column pending transforms; `ChunkerColumn` stores `requiredPreTransformEdges: EnumSet<Edge>` and one `Consumer<Map<Edge,ChunkerColumn>>` (`addPreTransformHandler(edges, fn)` ANDs handlers/unions edges; `preTransform(neighbours)` runs once then clears).
- `Edge` enum POSITIVE_X(1,0) NEGATIVE_X(-1,0) POSITIVE_Z(0,1) NEGATIVE_Z(0,-1) + `getRelative(ChunkCoordPair)`, `getOpposite`, `fromOffset`. (Only 4 edges, no diagonals.)
- `PreTransformManager` (abstract; per version/reader or writer; `registerHandler(handler, blockType...)` maps `ChunkerBlockType -> BlockPreTransformHandler`, entity class -> `EntityPreTransformHandler<T>`): `solve(column, preTransformAllowed)`: (1) entities: for each entity matching a handler (instanceof, first match wins) either solve now (if !allowed or handler.getRequiredEdges empty; handler.handle returns true => entity removed) or queue; (2) per chunk, skip if palette has no handled type, then loop y,x,z 16^3 (order y outer, x, z inner), get block from palette, if handler present compute required edges via `calculateEdges` (edge only if neighbouring block lies in a different chunk) -> solve now with empty neighbours (replace block if `!equals`) or queue `PendingBlockPreTransform(x,y,z)`; (3) if queued, `column.addPreTransformHandler(edges, neighbours -> solveEdges(...))` which re-reads the *current* block at x,y,z, calls handler with neighbours map, sets block if changed; entity pending skipped if no longer in column.
- Handler base types: `BlockPreTransformHandler{getRequiredEdges, handle(column, neighbours, x,y,z, id)->id, getRelative(...)}` with `Direction{NORTH(-Z) EAST(+X) SOUTH(+Z) WEST(-X) UP DOWN}`; `getRelative` returns AIR if the needed neighbour column is absent; `getRelativeBlockEntity`; helper interfaces `ConnectableBlockPreTransformHandler` (6 dirs -> sets boolean states north/east/south/west/up/down), `HorizontalConnectable...` (4 dirs), `SingleConnectable...` (1 dir) with abstract `canConnect(source, direction, relative)`.
- Concrete handlers (in encoding/, other agent's scope): Bedrock reader (version-gated): Stem, Wall, Door, Chest, Redstone, StairShape, FenceGate, HangingPlant, Fire, NoteBlock + anonymous Horizontal-connectables (tripwire, wooden fence, nether fence, glass pane/bars) for <1.26.50 etc.; Java legacy reader: Chest, TallPlants, Stem, Wall, FenceGate, Door, StairShape, Fire, Redstone, NoteBlock; modern Java reader/writer managers and Java writers: none registered; Bedrock writer registers only `BedrockPaintingEntityHandler.Relocator(true)` for PaintingEntity. QUIRK: writer-side `solve(column,true)` runs AFTER the reader-side transform pass, so any writer handler needing edges would register a handler that is never executed (painting relocator evidently needs none).
- `ColumnPreTransformConversionHandler` (the streaming neighbour-resolver; ~240 lines, **port carefully + port its tests**): constructed per world with `incompleteRegions = world.getRegions()`. State (all under `synchronized(this)`): `pending: region -> chunk -> ColumnData`, `incompleteRegions`, `flushedRegions`, `processedColumns: LongSet` (dup => IllegalArgumentException "Duplicate chunk processed"), ready queue. `ColumnData{requiredEdges, pendingCheckEdges(initially all 4), neighbours: Edge->ColumnData, queued, transformed, submitted}`. convertColumn: register; for each edge: neighbour pending => link both ways (resolve edge on both, enqueue neighbour if ready) else if neighbour's region is NOT incomplete (already flushed/known absent) => resolve edge as "absent"; enqueue self if no pending edges; `processReady`. `processReady`: pop ready, `column.preTransform(map of required-edge->neighbour column)`, mark transformed, `trySubmit` self and neighbours. `trySubmit(c)`: only if transformed && !submitted && every neighbour that REQUIRES an edge towards c is already transformed (so c is final before anyone reads it); then submit to delegate (`convertColumn`), remove from `pending` (and when a region's pending map empties -> `flushRegionIfComplete`), unlink from neighbours to free memory. `flushRegion(r)`: remove r from incomplete; resolve pending edges that point into r for columns in r and in 4 adjacent regions; process; `flushRegionIfComplete` (only forwards delegate.flushRegion once, when region not incomplete and no pending). `flushColumns` (end of world): task "Submitting remaining columns": clear incomplete, resolve all remaining edges, process, `checkState(pending.isEmpty())`, then `delegate.flushColumns` as continuation.
  Rust: plain struct behind `Mutex`, `EnumSet`->`u8` bitflags, `Rc`-less links via a slab/`HashMap<ChunkCoordPair, usize>` of ColumnData indexes (avoid Arc cycles), `ArrayDeque`->`VecDeque`.
- Est Rust: pipeline.rs ~250, pretransform handler ~350, manager+traits ~350, Edge/Direction ~100 => ~1050 lines (excluding concrete per-version handlers).

## 9. Java idioms needing redesign / gotchas checklist
- CompletableFuture/thread-local parent tracking -> explicit TaskCtx + countdown tree (sec 3).
- Class-hierarchy visitors: `PreTransformManager` maps `Class<? extends Entity>` via `isInstance` (first match in HashMap iteration order - nondeterministic if overlapping!) -> Rust: key by entity enum/TypeId; keep "first matching handler wins" deterministic.
- Reflection settings (sec 5), annotations, Gson reflection -> macro table + serde.
- Interior-null semantics (lazy maps, `null` list/array == empty) -> use empty containers; keep "empty equals null" equality.
- `Optional<Dimension>` + reference-equality of vanilla dimensions -> compare by identifier/ID or use `Arc::ptr_eq`; make `Dimension` `Arc<Dimension>`/cheap `Clone`.
- Checked exceptions thrown through lambdas (`ThrowableConsumer`, SneakyThrows) -> `Result<(), ConvertError>` everywhere; fatal vs non-fatal distinction: non-fatal = logged + flag, fatal = return Err from task.
- Null-returning handlers (`Task<WorldConversionHandler>` null) -> `Option<Arc<dyn ..>>`.
- Missing-id multimap de-dup + log-once.
- ThreadLocal `InheritableThreadLocal<TaskExecutor>`: also copied into any thread spawned from workers.
- Hard-coded: 8 worker threads, MAX_IN_FLIGHT_REGIONS=4, tag size limits (65536 arrays / 1M lists+compounds / 256 names / 32767 strings), `-Xss4m` stack in build (deeply nested NBT recursion; in Rust guard recursion depth or run workers with bigger stack, e.g. 8 MiB thread builder).
- Stream-compression finish semantics: Java helpers close streams (flush deflate trailer) before returning bytes; in Rust call `finish()`.
