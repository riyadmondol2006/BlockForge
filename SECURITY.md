# Security Policy

## Supported versions

Only the latest release is supported. BlockForge checks for updates and installs them with one click, so everyone can
be on the newest version.

## Reporting a vulnerability

Please report it privately with GitHub's
[private vulnerability reporting](https://github.com/riyadmondol2006/BlockForge/security/advisories/new) instead of
opening a public issue. Include what you found, how to reproduce it and which version and system you used. You will get
an answer as soon as possible, and the fix is released before the details are made public.

Things that count: leaking or mishandling account tokens, downloads that aren't verified, files written outside the
instance or data folders (for example from a modpack), and anything that runs code the player didn't ask for.
